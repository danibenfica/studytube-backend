# 🔌 4.4 Contrato da API e mapa de dados

> **FONTE TÉCNICA** O contrato OpenAPI é gerado pela própria API em `http://localhost:5126/openapi/v1.json` (Swagger UI em `/swagger`), somente no ambiente `Development`. Esta seção resume o contrato e o liga aos casos de uso; em caso de dúvida, vale o OpenAPI gerado.

**Base:** `http://localhost:5126/api/videos` · **Formato:** JSON em `camelCase` · **Autenticação:** não há · **CORS:** política `Frontends` (qualquer origem).

## 4.4.1 Endpoints

| Método e rota | Caso de uso | Corpo | Respostas |
|---|---|---|---|
| `GET /api/videos` | UC_002 | — | `200` array de `VideoDto` (ou `[]`), ordenado por `addedAt` decrescente. |
| `POST /api/videos` | UC_001 | `{ "url": "https://www.youtube.com/watch?v=dQw4w9WgXcQ" }` | `201` `VideoDto` + cabeçalho `Location: /api/videos/{id}` · `400 { "error": "..." }` (FE_02 a FE_06, FE_08) · `400` Problem Details sem `url` (FE_01) · `500` falha no YouTube (FE_07). |
| `PATCH /api/videos/{id}/watched` | UC_003 | — | `200` `VideoDto` · `400 { "error": "Este vídeo já foi marcado como assistido." }` · `404` id inexistente ou não-GUID. |
| `DELETE /api/videos/{id}/watched` | UC_004 | — | `200` `VideoDto` · `404` id inexistente ou não-GUID. |

`{id}` tem a restrição de rota `guid`. Não existe `GET /api/videos/{id}`, embora o `201` aponte `Location` para esse endereço (registrado no [Anexo E](anexo-e-registro-de-revisao.md)).

## 4.4.3 Mapa de dados — `VideoDto` ↔ entidade `Video` ↔ tabela `Videos` ↔ YouTube

| Campo JSON | Tipo JSON | Entidade `Video` | Coluna SQLite (`Videos`) | Origem do valor |
|---|---|---|---|---|
| `id` | string (GUID) | `Id` (`Guid`) | `Id` — chave primária | Gerado em `Video.Create` (`Guid.NewGuid()`). |
| `youTubeId` | string (11) | `YouTubeId` (`YouTubeVideoId`) | `YouTubeId` — `HasMaxLength(11)`, obrigatório, **índice único** | Extraído da URL (UC_007). |
| `title` | string | `Title` | `Title` — máx. 300, obrigatório | `snippet.title` (com `Trim`). |
| `channelTitle` | string | `ChannelTitle` | `ChannelTitle` — máx. 200 | `snippet.channelTitle` (com `Trim`). |
| `thumbnailUrl` | string | `ThumbnailUrl` | `ThumbnailUrl` — máx. 500 | `snippet.thumbnails.high.url`, senão `default.url`, senão vazio. |
| `duration` | string `TimeSpan` (ex.: `"00:04:13"`, `"1.02:03:04"`) | `Duration` (`TimeSpan`) | `Duration` | `contentDetails.duration` ISO 8601 (`PT4M13S`) convertido com `XmlConvert.ToTimeSpan`. |
| `watched` | boolean | `Watched` | `Watched` | `false` na criação; muda em UC_003/UC_004. |
| `addedAt` | string data/hora | `AddedAt` | `AddedAt` | `DateTime.UtcNow` na criação. |
| `watchedAt` | string data/hora ou `null` | `WatchedAt` | `WatchedAt` | `DateTime.UtcNow` ao marcar; `null` ao desmarcar. |

**Observação sobre datas.** Os valores são gravados em UTC. Ao ler do SQLite, o EF Core pode devolver `DateTimeKind.Unspecified`, então o `GET` pode mostrar a data sem o sufixo `Z`, enquanto o `POST`/`PATCH` pode mostrar com `Z`. Clientes devem tratar as duas formas.

**Persistência.** Tabela criada pela migration `20261018220638_InitialCreate`, aplicada automaticamente por `Database.Migrate()` ao iniciar a API.
