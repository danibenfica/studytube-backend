# ⚙️ 4.6 Procedimento operacional

> **AMBIENTE** Só existe ambiente **local de desenvolvimento**. Não há staging nem produção, nem monitoramento ou alertas configurados.

## 4.6.1 Pré-requisitos

- .NET SDK 10 (o `global.json` fixa `10.0.400` com `rollForward: latestFeature`).
- Ferramenta `dotnet-ef` (opcional, para gerenciar migrations manualmente).
- Uma chave da YouTube Data API v3 (Google Cloud Console → APIs e serviços → Credenciais).

## 4.6.2 Configurar a chave (sem expor o segredo)

```powershell
cd StudyTube.Api
dotnet user-secrets set "YouTube:ApiKey" "<SUA_CHAVE>"
```

A chave fica fora do repositório, no perfil do usuário (`%APPDATA%\Microsoft\UserSecrets\<UserSecretsId>\secrets.json` no Windows). **Nunca** coloque a chave em `appsettings.json`, em commits ou nesta documentação.

## 4.6.3 Executar

```powershell
dotnet run --project StudyTube.Api --launch-profile http
```

| Recurso | Endereço |
|---|---|
| API | http://localhost:5126/api/videos |
| Swagger UI | http://localhost:5126/swagger |
| OpenAPI | http://localhost:5126/openapi/v1.json |

O perfil `https` usa `https://localhost:7271` (e também `http://localhost:5126`).

## 4.6.4 Banco e migrations

- Connection string: `Data Source=studytube.db` → arquivo `StudyTube.Api/studytube.db` (ignorado pelo Git).
- As migrations são aplicadas automaticamente na inicialização (`Database.Migrate()`).
- Para recriar o banco do zero: pare a API, apague `studytube.db` e inicie de novo. **Isso apaga a lista.**

## 4.6.5 Testes e CI

```powershell
dotnet test StudyTube.slnx
dotnet test StudyTube.slnx --filter "FullyQualifiedName~StudyTube.Tests.Integration"
```

O workflow `CI` roda em todo push na `main` e em todo pull request: `dotnet restore` → `dotnet build --configuration Release` → `dotnet test` em `ubuntu-latest` e `windows-latest`.

## 4.6.6 Diagnóstico rápido

| Sintoma | Causa provável | Ação segura |
|---|---|---|
| `POST` devolve `500` | Chave do YouTube ausente, recusada ou cota esgotada; ou sem internet. | Conferir `dotnet user-secrets list` e o console da API; testar a chave no Google Cloud Console. |
| Frontend mostra "Não consegui falar com a API" | API parada ou em outra porta. | Subir com `--launch-profile http` (porta 5126). |
| Erro ao iniciar sobre o banco | Arquivo `studytube.db` corrompido ou bloqueado. | Fechar programas que usam o arquivo; em último caso apagar o arquivo (perde a lista). |
