# 📝 4.3 Histórias de usuário e critérios de aceitação

> **POR QUE OS DOIS?** O caso de uso mostra o comportamento completo (fluxo principal, alternativos e exceções). A história de usuário resume o valor para o estudante em uma frase ("Como <papel>, quero <ação>, para <benefício>") e define **critérios de aceitação** verificáveis. Cada história aponta para o caso de uso que a detalha, e cada critério aponta para o fluxo (FP, FA ou FE) que o descreve.

Os mesmos códigos `US_xxx` são usados na documentação do frontend. Aqui os critérios estão escritos do ponto de vista da **API**; no frontend, do ponto de vista da **tela**.

## US_001 – Adicionar videoaula pelo link (UC_001, RF01, RF05)

**Como** estudante, **quero** adicionar uma videoaula informando só o link do YouTube, **para** montar minha lista de estudos sem digitar título, canal e duração.

| # | Critério de aceitação (Dado / Quando / Então) | Fluxo |
|---|---|---|
| CA1 | **Dado** um link válido de um vídeo que existe e ainda não está na lista, **quando** envio `POST /api/videos`, **então** recebo `201 Created`, o cabeçalho `Location` e o `VideoDto` com título, canal, miniatura, duração e `watched = false`. | FP |
| CA2 | **Dado** um link `youtu.be`, `/embed/` ou `/shorts/`, **quando** envio o link, **então** o vídeo é cadastrado do mesmo jeito. | FA_01 |
| CA3 | **Dado** um texto que não é URL absoluta, **quando** envio, **então** recebo `400` com `"URL inválida."`. | FE_02 |
| CA4 | **Dado** uma URL de outro site ou de página do YouTube que não é vídeo, **quando** envio, **então** recebo `400` com `"Não é uma URL de vídeo do YouTube."`. | FE_03 |
| CA5 | **Dado** um ID com tamanho ou caracteres inválidos, **quando** envio, **então** recebo `400` com `"ID do YouTube inválido."`. | FE_04 |
| CA6 | **Dado** um vídeo que já está na lista, **quando** envio de novo, **então** recebo `400` com `"Este vídeo já está na sua lista."` e nada é duplicado. | FE_05 |
| CA7 | **Dado** um ID que o YouTube não devolve, **quando** envio, **então** recebo `400` com `"Vídeo não encontrado no YouTube."`. | FE_06 |

## US_002 – Ver minha lista de videoaulas (UC_002, RF02)

**Como** estudante, **quero** ver todas as videoaulas que adicionei, com as mais recentes primeiro, **para** saber o que tenho para estudar.

| # | Critério de aceitação | Fluxo |
|---|---|---|
| CA1 | **Dado** que existem videoaulas, **quando** envio `GET /api/videos`, **então** recebo `200` com um array de `VideoDto` ordenado por `addedAt` decrescente. | FP |
| CA2 | **Dado** que não existem videoaulas, **quando** consulto, **então** recebo `200` com `[]`. | FP |

## US_003 – Marcar videoaula como assistida (UC_003, RF03)

**Como** estudante, **quero** marcar uma videoaula como assistida, **para** saber o que já estudei.

| # | Critério de aceitação | Fluxo |
|---|---|---|
| CA1 | **Dado** uma videoaula não assistida, **quando** envio `PATCH /api/videos/{id}/watched`, **então** recebo `200` com `watched = true` e `watchedAt` preenchido. | FP |
| CA2 | **Dado** um `id` inexistente, **quando** envio, **então** recebo `404`. | FE_01 |
| CA3 | **Dado** uma videoaula já assistida, **quando** envio de novo, **então** recebo `400` com `"Este vídeo já foi marcado como assistido."`. | FE_02 |

## US_004 – Desmarcar videoaula (UC_004, RF04)

**Como** estudante, **quero** desmarcar uma videoaula, **para** corrigir uma marcação feita por engano ou rever o conteúdo.

| # | Critério de aceitação | Fluxo |
|---|---|---|
| CA1 | **Dado** uma videoaula assistida, **quando** envio `DELETE /api/videos/{id}/watched`, **então** recebo `200` com `watched = false` e `watchedAt = null`. | FP |
| CA2 | **Dado** uma videoaula já desmarcada, **quando** envio, **então** recebo `200` sem erro (RN07). | FP |
| CA3 | **Dado** um `id` inexistente, **quando** envio, **então** recebo `404`. | FE_01 |

## US_005 e US_006 – Assistir na página e acompanhar o progresso

Executadas apenas na interface web (UC_005 e UC_006). A API participa só fornecendo `youTubeId` e `watched` em `GET /api/videos`. Ver a documentação do frontend.
